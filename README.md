# website
A full-stack RAG demo you can run locally or deploy to a VPS: upload a PDF, build a per-browser vector index (FAISS), chat with an LLM using retrieved context. The UI is a React + TypeScript SPA; the API is FastAPI + LangChain with a multi-agent pipeline, Sentry tunneling, &amp; sensible production defaults (CORS, rate limits, session disk cleanup)
